# UIUX Color Rules — LabCircuitos (tema claro)

1. Primary: `primary-500` (#1F4D3A) — acciones, mediciones, selección
2. Gold: `gold-500` (#C9A86A) — botón INICIAR, highlights
3. Success: `sim-running` / green-50 backgrounds
4. Warning: `sim-processing` / yellow-50
5. Error: `sim-error` / red-50
6. Surfaces: `surface-950` (canvas), `surface-900` (paneles), `surface-800` (cards), `surface-700` (borders)
7. Text: `text-ink`, `text-ink-muted`, `text-ink-faint`
8. No emojis: use initial-letter boxes or text badges instead
9. Referencia completa: `docs/TEMA_UI.md`
